# 09-privacy-and-numbers — alt text (paste per slide in Instagram → Advanced settings → Accessibility)

01. Offline is not just a setting in YazSes. The test suite enforces it.
02. By default no audio and no text leave your machine. No account, no API key, no telemetry.
03. The build fails if code gains a network call that has not been registered and reviewed.
04. Benchmarks: 4.07 percent word error rate, 1.56 second median decode, 0.29 milliseconds of pipeline overhead.
05. Honest limits: not an AI agent, English models by default, desktop only, and cloud speech-to-text may beat it on a noisy mic.
06. The cost is published before you install: about 1.1 GB plus a 141 MB model, and a complete uninstall guide.
07. Check our claims. That's the point. Docs at mskazemi.com/yazses, code at github.com/MSKazemi/yazses. Free, Apache-2.0, offline. QR code (Benchmarks): https://mskazemi.com/yazses/benchmarks.html.
