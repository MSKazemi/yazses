# Install on macOS & Windows - Instagram caption (English)

Offline dictation on Mac and Windows: developer preview. 🍎🪟

macOS: Homebrew on Apple Silicon, a .dmg for Intel.
Windows: `winget install MSKazemi.YazSes`

The builds are not code-signed yet, so the first launch takes a few extra clicks. On a Mac it asks for three permissions (Accessibility, Input Monitoring, Microphone). Slides 3 and 4 show what to click and why.

Then hold Right Option (Mac) or Right Ctrl (Windows) and talk.
