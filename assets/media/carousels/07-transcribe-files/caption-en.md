# Transcribe files offline - Instagram caption (English)

Transcribe any recording without uploading it. 📄

`yazses transcribe interview.m4a` → interview.txt, right next to it.

Subtitles (srt/vtt), Markdown or JSON. Speaker labels with `--diarize`. Better accuracy with
`--model small.en`. English text from other languages with `--model small --language translate`.

Don't take our word that it's offline: run it in Docker with `--network none` and watch it still work.
