# 05-configure — alt text (paste per slide in Instagram → Advanced settings → Accessibility)

01. Make YazSes yours: change the hotkey, pin your microphone and trade speed for accuracy, mostly without editing a file.
02. Change the hold-to-talk key with yazses hotkey set, then restart. Real output of hotkey show.
03. Pin your microphone by name so a monitor or headset cannot silently steal capture.
04. Choose accuracy versus speed. Word error rate on LibriSpeech test-clean: tiny.en 4.82 percent, base.en 4.07 percent, small.en 2.59 percent.
05. Other languages: the .en models are English-only. Use a multilingual model such as small and set the language code.
06. Teach it your words: yazses vocab add for names and jargon it mis-hears.
07. Change one thing at a time. Docs at mskazemi.com/yazses, code at github.com/MSKazemi/yazses. Free, Apache-2.0, offline. QR code (How-to guides): https://mskazemi.com/yazses/how-to/index.html.
