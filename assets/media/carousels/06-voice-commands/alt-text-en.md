# 06-voice-commands — alt text (paste per slide in Instagram → Advanced settings → Accessibility)

01. Don't just dictate, command. YazSes turns phrases like undo that or go to line 42 into key presses.
02. Examples of voice commands and what they do.
03. Say scratch that to drop the last phrase. On by default.
04. Voice punctuation is opt-in: say hello comma world period to get hello, world.
05. A dedicated command key: while you hold it, everything you say is a command and is never typed.
06. Macros: say a trigger phrase on its own to insert a saved snippet. Defined in macros.toml.
07. Talk to your editor. Docs at mskazemi.com/yazses, code at github.com/MSKazemi/yazses. Free, Apache-2.0, offline. QR code (Voice commands): https://mskazemi.com/yazses/use-cases/voice-commands.html.
