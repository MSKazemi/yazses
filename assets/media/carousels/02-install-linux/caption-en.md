# Install on Linux - Instagram caption (English)

Voice dictation on Linux, X11 and Wayland, in one line. 🐧

The installer sets up everything dictation needs (audio, typing tools, the input group, ydotoold
for GNOME/KDE Wayland) and finishes by checking its own work.

Don't like piping curl into bash? Fair. Add `--dry-run` and it prints every change without making
any. The install size and the uninstall guide are both published up front.

The step people miss: log out and back in once. Slide 4 explains why.
