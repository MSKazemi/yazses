# 02-install-linux — alt text (paste per slide in Instagram → Advanced settings → Accessibility)

01. Install YazSes on Linux in one line. Works on X11 and Wayland.
02. The one-line installer command and what it does.
03. Run it with --dry-run first: it prints every change it would make and makes none.
04. Log out and back in once. A new terminal tab is not enough; the input group needs a new login session.
05. Check it with yazses doctor. Real output excerpt showing OK for keyboard capture, microphone, Wayland and injection.
06. Other ways to install on Linux: APT script, pipx, Snap Store, and a Docker image for file transcription.
07. Installed? Now set it up. Docs at mskazemi.com/yazses, code at github.com/MSKazemi/yazses. Free, Apache-2.0, offline. QR code (Linux guide): https://mskazemi.com/yazses/install-linux.html.
