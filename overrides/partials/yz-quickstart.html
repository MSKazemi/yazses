Quick start

From zero to your first dictated sentence

Three steps, a few minutes, no account. The speech model downloads once; after that, dictation never touches the network.

  1. Install

    bash <(curl -fsSL https://raw.githubusercontent.com/MSKazemi/yazses/main/install.sh)

    One command for Ubuntu, Debian, Fedora, Arch and their relatives. It installs YazSes plus the audio, hotkey and typing helpers your session needs, then runs yazses doctor.

    APT, Snap or pipx instead → 
    brew tap MSKazemi/yazses
brew trust MSKazemi/yazses
brew install --cask yazses

    Apple Silicon. On an Intel Mac, download the x86_64 .dmg from the releases page instead.

    The macOS guide → 
    winget install MSKazemi.YazSes

    winget can trail the newest release by a few weeks; the installer, Scoop and Chocolatey track every one. The build is not code-signed yet, so SmartScreen asks once: More info → Run anyway.

    The Windows guide → 
    pipx install yazses

    Any OS with Python 3.11 or newer. On Linux, follow it with yazses setup, which installs the audio and typing helpers.

    Will it run on my machine? →

  2. Allow and check

    yazses doctor
yazses mic-level --set

    If doctor says you were added to the input group, log out and back in once. mic-level --set tunes the voice gate to your microphone and room.

    Something flagged? →

    Open YazSes from Applications (on macOS 15+, the first blocked launch is approved with Open Anyway in Privacy & Security). Then switch it on under Accessibility, Input Monitoring and Microphone, and relaunch it. Input Monitoring is the switch people miss.

    Why there are three switches →

    YazSes starts in the system tray, next to the clock. If Windows asks about the microphone, allow it. The tray icon’s colour shows what it is doing.

    What the tray colours mean → 
    yazses doctor

    Checks the microphone, the hotkey, the typing backend and permissions, and names the fix for anything that is missing.

    Something flagged? →

  3. Dictate

    yazses start

    Now hold Right Alt, speak, and release. The words are typed wherever your cursor is, in any app, on X11 or Wayland.

    Hold Right Option, speak, and release. The words are typed into whichever app has focus.

    Hold Right Ctrl, speak, and release. The words are typed into whichever app has focus.

    yazses start

    Hold the hotkey (Right Alt on Linux, Right Option on macOS, Right Ctrl on Windows), speak, and release.
