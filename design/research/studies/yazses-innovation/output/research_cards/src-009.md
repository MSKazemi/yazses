## Summary

This practitioner benchmark article (ruoqijin.com/blog, "ASR in 2025-2026: A Deep Dive") provides a comparative analysis of current ASR stacks for real-world offline and cloud deployment. [EVIDENCE src-009] Key findings relevant to YazSes include: Whisper-base.en achieves approximately 5% WER on clear English speech; streaming latency for cloud services (Deepgram Nova-2 ~150 ms, Azure ~200 ms) is materially lower than offline Whisper streaming (~380–520 ms); and WER on coding/technical vocabulary roughly doubles compared to general English WER. [EVIDENCE src-009]

## Key Findings

- **Whisper-base.en WER:** Achieves approximately 5% word error rate on clear English speech. [EVIDENCE src-009] This is the primary model tier YazSes uses by default.
- **Streaming latency comparison:** Deepgram Nova-2 ~150 ms end-to-end, Azure Cognitive Services ~200 ms, Whisper streaming ~380–520 ms on CPU. [EVIDENCE src-009] The offline penalty vs. cloud is approximately 2–3× for streaming latency.
- **Offline alternatives:** For offline tools, Vosk and whisper.cpp are identified as the main alternatives to faster-whisper. [EVIDENCE src-009] Vosk offers lower memory footprint; whisper.cpp offers better cross-platform build simplicity.
- **Technical vocabulary WER doubling:** For coding and technical vocabulary (function names, CLI commands, identifiers), general ASR WER approximately doubles. [EVIDENCE src-009] This means Whisper-base.en's ~5% WER becomes ~10% on code-heavy dictation — a significant accuracy gap for developer users.
- **Domain adaptation requirement:** The technical vocabulary finding implies that general ASR alone is insufficient for developer dictation without a correction or adaptation layer. [EVIDENCE src-009]
- **Vosk characteristics:** Vosk is highlighted for its lower memory footprint relative to Whisper. [EVIDENCE src-009] This could make it relevant for embedded/IoT or very low-RAM devices.

## Gaps Surfaced

- **gap-techvocab-1:** The ~2× WER increase on technical vocabulary is reported as an approximate finding without a controlled benchmark corpus. [EVIDENCE src-009] A YazSes-specific technical vocabulary benchmark (with common coding identifiers, CLI commands, framework names) is needed to quantify this accurately.
- **gap-techvocab-2:** The benchmark does not test domain-adapted models (e.g. Whisper fine-tuned on code corpora) — it is unknown how much fine-tuning can recover the WER gap.
- **gap-offline-latency-1:** The 380–520 ms offline streaming latency figure comes from whisper_streaming; there is no independent benchmark of faster-whisper with the WhisperPipe consensus engine on CPU. [TODO: find source]
- **gap-vosk-1:** Vosk's streaming latency and WER on technical vocabulary are not benchmarked in this article — a gap if YazSes considers Vosk as a low-resource fallback backend.
