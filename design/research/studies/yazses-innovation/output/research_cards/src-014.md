## Summary

This Springer/Frontiers of Computer Science 2025 survey examines multimodal natural interaction (voice, eye gaze, hand gesture) for XR headsets. [EVIDENCE src-014] Key quantitative findings: voice latency must be under 200 ms for real-time feel; latency above 400 ms causes a perceived speech-action disconnect. [EVIDENCE src-014] Three-modality fusion (voice + eye gaze + hand gesture) achieves 94% intent accuracy vs. 78% voice-only in 3D object selection tasks. [EVIDENCE src-014] The survey concludes that voice is best suited for text input and complex commands in XR, while gaze and gesture are better for spatial selection.

## Key Findings

- **200 ms real-time threshold:** Voice command latency must be below 200 ms for users to perceive interaction as real-time. [EVIDENCE src-014] This is consistent with findings in src-011 and establishes a consensus threshold.
- **400 ms disconnect threshold:** At >400 ms, users perceive a noticeable speech-action disconnect — the sense that the system is not responding to their voice. [EVIDENCE src-014] Whisper streaming's 380–520 ms places it at the edge of this threshold.
- **Three-modality fusion accuracy:** Combining voice, eye gaze, and hand gesture achieves 94% intent accuracy for 3D object selection vs. 78% voice-only. [EVIDENCE src-014] The 16-point accuracy gain from adding gaze and gesture is substantial.
- **Voice best for text + complex commands:** The survey concludes that voice excels for text input and complex natural language commands in XR, while gaze and gesture are more efficient for spatial object selection. [EVIDENCE src-014] This provides clear design guidance for YazSes's XR integration scope.
- **Modality fusion design:** The survey describes fusion architectures that combine modality-specific confidence scores with a joint intent classifier. [EVIDENCE src-014] Voice confidence from ASR + gaze confidence from eye tracking + gesture confidence from hand tracking are merged probabilistically.
- **Headset-specific challenges:** The survey notes that headset audio capture (proximity, breath noise, movement) and compute constraints (thermal throttling) are unresolved engineering challenges for on-device multimodal processing. [EVIDENCE src-014]

## Gaps Surfaced

- **gap-xr-latency-2:** YazSes's current streaming latency (380–520 ms from src-002) exceeds both the 200 ms real-time threshold and approaches the 400 ms disconnect threshold. [EVIDENCE src-014] Closing this gap to <200 ms on CPU requires architectural changes beyond LocalAgreement tuning alone.
- **gap-multimodal-1:** YazSes is voice-only; the 16-point accuracy gain from adding eye gaze suggests that an optional gaze input integration (via XR SDK) would substantially improve spatial command accuracy in XR deployments.
- **gap-thermalthrottle-1:** Thermal throttling in XR headsets degrades CPU/GPU performance over time, increasing ASR latency during extended sessions. YazSes's latency figures are measured under steady-state conditions; thermal degradation is not characterised.
- **gap-modality-voice-scope-1:** The survey's recommendation to use voice for "complex commands" is not operationalised with a definition of complexity. A concrete complexity classifier for YazSes's command routing layer is needed.
