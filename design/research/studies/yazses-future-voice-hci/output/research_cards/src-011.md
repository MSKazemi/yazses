## Source Summary

This is the call-for-papers and session description for a special session at Interspeech 2025, the flagship venue for speech technology research. The session is dedicated to "biosignal-enabled spoken communication" — the use of articulatory biosignals (EMG, ultrasound tongue imaging) and neural signals (EEG, MEG, ECoG) for speech recognition, synthesis, and enhancement. The session identifies five key application areas: silent speech interfaces, speech restoration for voice-impaired individuals, neuro-steered hearing aids, voice conversion for AAC, and auditory attention detection. This session represents official recognition by the speech technology community that biosignal-augmented voice is a mature enough research direction to warrant a dedicated venue track.

- [HYPOTHESIS] The inclusion of auditory attention detection (which signal is the user listening to, based on EEG) in the session scope suggests that future voice interfaces may be able to identify when a user is paying attention to a specific audio stream and respond accordingly — an ambient mode capability.
- [HYPOTHESIS] The session's focus on voice conversion for AAC (generating a natural-sounding voice from dysarthric input) is relevant for a YazSes "voice normalisation" mode that improves transcription accuracy for users with atypical speech patterns.

## Technical Mechanisms

### Architecture / System Design

[EVIDENCE src-011] The session covers the full biosignal-to-speech pipeline: sensor acquisition → signal processing → feature extraction → recognition/synthesis model → application output. The session explicitly includes work on any of these stages.

### Core Algorithms or Methods

[EVIDENCE src-011] Methods in scope include: EMG-based silent speech recognition, neural decoding of speech (EEG/MEG/ECoG), ultrasound-based articulatory tracking, neuro-steered beam forming for hearing aids, and voice conversion models for AAC. [HYPOTHESIS] The neuro-steered hearing aid application (detecting which sound the user is attending to from EEG and enhancing it) has a direct analogue for voice daemons: detecting when the user intends to speak (pre-speech neural readiness potential) to trigger the STT pipeline before acoustic onset.

### Key Data Structures or APIs

[EVIDENCE src-011] The session implies datasets and benchmarks will be presented; specific open datasets are not named in the call. The referenced lab (Prof. Schultz at Bremen) has previously released the EMG-UKA corpus, a benchmark dataset for EMG silent speech recognition.

## Applicability to Project

[EVIDENCE src-011] The session's five application areas map directly to YazSes capability opportunities: (1) silent speech → EMG input mode; (2) speech restoration → dysarthria-robust transcription mode; (3) neuro-steered attention → pre-speech trigger for ambient mode; (4) AAC voice conversion → personalised voice normalisation; (5) auditory attention → context-aware ambient activation. [HYPOTHESIS] YazSes could position itself as the open-source infrastructure layer for all five of these applications on desktop — none of the academic research systems target desktop integration.

[EVIDENCE src-011] The Tanja Schultz lab (University of Bremen) has published open biosignal datasets and tools. [HYPOTHESIS] Collaboration or open-source integration with this lab's tools could give YazSes a research-grade biosignal backend while the lab gains a deployment platform for their research — a mutually beneficial partnership worth pursuing.
