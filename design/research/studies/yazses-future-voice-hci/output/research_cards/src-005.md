## Source Summary

This April 2025 arXiv paper presents a silent speech interface that integrates multi-channel textile electromyography (EMG) electrodes into the earmuffs of standard headphones. The system captures jaw and facial muscle activation patterns when the user articulates words silently (mouthing without vocalisation), and achieves 96% accuracy on a 10-word command vocabulary in real-time wireless operation. The headphone form factor is significant: it makes EMG capture unobtrusive for the typical computer user who already wears headphones. This is one of the first demonstrations of high-accuracy silent-speech command recognition in a consumer-ready form factor.

---

## Key Claims

- [EVIDENCE src-005] 96% classification accuracy on a 10-word control vocabulary using textile EMG electrodes embedded in headphone earmuffs.
- [EVIDENCE src-005] The system operates wirelessly in real-time without cables or external hardware beyond the modified headphones.
- [EVIDENCE src-005] The command vocabulary covers practical control words relevant to computer interaction (specific words not named in the preprint abstract, but the evaluation targets "commonly used voice-free control words").
- [HYPOTHESIS] A 10-word vocabulary covers the most frequent YazSes hotkey-equivalent commands (start, stop, cancel, undo, paste, delete, confirm, next, back, help) — enough for a useful "silent mode" without full dictation.
- [EVIDENCE src-005] EMG electrodes in the earmuff position capture masseter and temporalis muscle activity during silent articulation; this position is stable due to the headphone housing providing consistent electrode contact.
- [HYPOTHESIS] Consumer EMG headphones could be available at ~$150–300 within 3 years given current trajectory (Nextmind was acquired by Snap; Meta and Apple have published EMG wearable patents), making this a practical YazSes extension target.

## Technical Mechanisms

### Architecture / System Design

[EVIDENCE src-005] The pipeline: textile EMG electrodes (earmuff) → wireless transmitter → laptop/PC → signal processing (bandpass filter 20–450 Hz, notch at 50/60 Hz) → feature extraction (RMS, zero-crossing rate per channel) → classification model → command output. No microphone is used; the system is entirely muscle-activation-based.

### Core Algorithms or Methods

[EVIDENCE src-005] Classification uses a machine learning model (specific architecture not stated in the abstract — likely SVM or shallow CNN based on the feature description). The model is trained per-user with a short calibration session. [HYPOTHESIS] With modern transformer-based EMG decoders (see src-006), accuracy on command vocabularies > 10 words could be substantially higher, suggesting the 96% figure is a lower bound on what is achievable with state-of-the-art models.

### Key Data Structures or APIs

[EVIDENCE src-005] The output is a discrete command label from the vocabulary — directly mappable to YazSes IPC commands (inject, status, remote_start, etc.) without any transcription intermediate step.

## Identified Gaps

### Stated Limitations

- [EVIDENCE src-005] Vocabulary is limited to 10 words; full sentence-level dictation is not demonstrated.
- [EVIDENCE src-005] Per-user calibration is required; transfer across users is not evaluated.

### Inferred Gaps

- [HYPOTHESIS] Accuracy likely degrades significantly when the user is chewing, speaking aloud, or making other jaw movements not in the training set — robustness to everyday interference is not reported.
- [HYPOTHESIS] The 10-word ceiling means this system is a command interface, not a dictation replacement; integration with YazSes would require a hybrid mode (EMG for commands, voice for dictation).

### Evaluation / Coverage Gaps

- [EVIDENCE src-005] Evaluation appears to be in a controlled lab setting; real-world performance with head movement, chewing, and environmental EMG interference is not reported.

## Applicability to Project

[EVIDENCE src-005] The headphone EMG form factor directly enables a "silent mode" for YazSes: users in open offices or public spaces who cannot speak aloud could activate start/stop/cancel without any vocalization. [HYPOTHESIS] YazSes could implement a hardware abstraction layer for EMG input devices that maps the 10-word command vocabulary to IPC method calls — the same interface used by the hotkey backend — making EMG a first-class input modality with minimal code changes.

[EVIDENCE src-005] The 96% accuracy at 10 commands is sufficient for a practical product. The IPC command set (status, shutdown, inject, remote_start/stop, enroll_start, streaming_enable/disable) already maps to ≤ 10 commands, meaning full IPC control via silent EMG input is technically feasible today with this system's accuracy. [HYPOTHESIS] A YazSes "EMG backend" that implements the same HotkeyBackend protocol as the existing evdev backend would integrate with zero changes to the daemon or CLI.
