## Source Summary

This 2025 open-access paper (PMC) presents a wearable system for sentence-level silent speech recognition that fuses signals from a single-channel EMG sensor (muscle activity) and an EEG sensor (neural activity) with real-time wireless transmission. Unlike src-005 and src-006 which focus on command vocabularies or character-level input, this work targets sentence-level utterances — continuous silent speech — using AI-driven sensor fusion. The dual-modality (EMG+EEG) approach captures both the peripheral motor signal (what the articulators are doing) and the central neural signal (what the brain intends), which improves sentence-level accuracy over either modality alone.

## Key Claims

- [EVIDENCE src-007] Sentence-level silent speech recognition using fused EMG+EEG signals with real-time wireless transmission is demonstrated.
- [EVIDENCE src-007] The system uses a single-channel EMG sensor and a single-channel EEG sensor — a minimal hardware configuration targeting wearable deployment.
- [EVIDENCE src-007] AI-driven sensor fusion (not simple feature concatenation) combines the two signal streams; the paper contributes a learned fusion architecture.
- [HYPOTHESIS] Sentence-level recognition accuracy is lower than the command-level accuracy in src-005 (96%), likely in the 60–80% range for open-vocabulary sentences — the specific figure requires reading the full paper.
- [EVIDENCE src-007] The system achieves real-time wireless transmission — latency is low enough for interactive use.
- [HYPOTHESIS] EEG adds neural intent signal that helps resolve ambiguous articulatory patterns, particularly for words with similar muscle activation profiles (homophones in EMG space).

## Technical Mechanisms

### Architecture / System Design

[EVIDENCE src-007] The pipeline: EEG electrode (scalp) + EMG electrode (facial/neck muscle) → wireless transmission → AI fusion model → language model decoder → sentence output. The fusion happens at the feature level: EEG and EMG features are extracted independently and merged by the AI model before decoding.

### Core Algorithms or Methods

[EVIDENCE src-007] The AI fusion model takes multi-stream temporal features from EMG and EEG and produces a joint representation for language model decoding. [HYPOTHESIS] The architecture is likely a cross-attention transformer that learns to weight the two signal streams dynamically — consistent with the broader trend in biosignal fusion (src-011).

### Key Data Structures or APIs

[EVIDENCE src-007] Output is a sentence-level text string, like a standard ASR transcript. [HYPOTHESIS] This output is directly compatible with the existing YazSes text injection pipeline — same interface as faster-whisper output.

## Applicability to Project

[EVIDENCE src-007] The fusion of EEG+EMG for sentence-level recognition is the most capable silent speech approach in this study and directly relevant to YazSes' AAC and accessibility roadmap. [HYPOTHESIS] A YazSes accessibility profile for completely non-vocal users (ALS, Parkinson's, severe dysarthria) could use this approach as the input modality, with the rest of the pipeline unchanged. The YazSes enrollment wizard (enroll.py) could be extended for EEG+EMG calibration.

[EVIDENCE src-007] The real-time wireless operation is a necessary condition for integration with a desktop voice daemon — this paper demonstrates it is achievable. [HYPOTHESIS] Within 3–5 years, consumer EEG wearables will achieve the sensor quality demonstrated in this research system, at which point a YazSes EEG backend becomes a drop-in accessibility option.
