# YazSes showcase

A static, dependency-free overview of [YazSes](https://github.com/MSKazemi/yazses), a free and
open-source hold-to-talk voice-dictation program. Speech is recognised on the user's own
computer by default.

This page is an overview. It does not run YazSes. To try speech recognition in a browser, use the
[hosted demo](https://huggingface.co/spaces/mskazemi/yazses-offline-transcription-demo). That demo
processes audio on Hugging Face infrastructure. To install YazSes for private, offline use, see the
[documentation](https://mskazemi.com/yazses/).
