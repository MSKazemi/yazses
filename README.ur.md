‏YazSes ایک مفت، اوپن سورس اور آف لائن آواز سے لکھنے والی سروس ہے جو Linux، macOS اور Windows پر چلتی ہے۔ ایک کلید دبائے رکھیں، بولیں، اور چھوڑ دیں — متن وہیں آ جاتا ہے جہاں آپ لکھ رہے ہیں۔ سب کچھ آپ ہی کے کمپیوٹر پر چلتا ہے: نہ کلاؤڈ، نہ اکاؤنٹ، نہ سبسکرپشن۔

## تنصیب

| پلیٹ فارم | کمانڈ |
|---|---|
| **Linux** | `bash <(curl -fsSL https://raw.githubusercontent.com/MSKazemi/yazses/main/install.sh)` |
| **Linux** (Debian/Ubuntu, APT) | `bash <(curl -fsSL https://raw.githubusercontent.com/MSKazemi/yazses/main/install-apt.sh)` |
| **کوئی بھی نظام** (Python ≥ 3.11) | `pipx install yazses` |

```bash
yazses quickstart
yazses start
```

پہلی بار چلانے پر ایک بار تقریر کا ماڈل (تقریباً 148 MB) ڈاؤن لوڈ ہوتا ہے۔ اس کے بعد نیٹ ورک کی بالکل ضرورت نہیں رہتی۔

## یہ کیا کرتا ہے

- **املا** — کلید دبائے رکھیں، بولیں، چھوڑ دیں۔ متن فعال ونڈو میں لکھا جاتا ہے۔
- **آوازی کمانڈز** — کہیے «فائل محفوظ کرو» یا «لائن 40 پر جاؤ» — یہ الفاظ لکھنے کے بجائے کام کر دے گا۔
- **میٹنگز اور ریکارڈنگز** — کسی آڈیو فائل کو متن میں بدلیں، یا پوری میٹنگ بولنے والوں کی نشاندہی کے ساتھ ریکارڈ کریں — سب آف لائن۔
