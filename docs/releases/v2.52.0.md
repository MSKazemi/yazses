# v2.52.0 — Toggle dictation, a camera off switch, and any local server for LLM cleanup

**Released 2026-11-26.** Upgrade:

```sh
sudo snap refresh yazses     # snap
pipx upgrade yazses          # or: uv tool upgrade yazses
scoop update yazses          # Windows
```

Restart the daemon afterwards (`yazses restart`). The new settings are off or unchanged by default. A few
behaviours do change on their own; see [Behaviour changes](#behaviour-changes).

## What you will notice

- **Toggle dictation.** With `[hotkey] mode = "toggle"`, press the dictation key once to start recording and
  again to stop, instead of holding it. The default stays `"hold"`.
- **Free the webcam for a video call.** `yazses camera off` releases the camera for every YazSes camera feature,
  and `yazses camera on` takes it back. The tray has a matching **Camera** entry when a camera feature is
  enabled. Voice dictation is not affected.
- **Pick a webcam by name.** `yazses camera list` shows the cameras, `yazses camera use <name-or-path>` switches
  to one, and `--save` remembers it across restarts.
- **See and remove downloaded models.** `yazses model list` now covers every kind of model, and
  `yazses model disk` and `yazses model remove` are new.
- **Faster typing, if you want it.** `[injection] type_delay_ms` sets the delay per typed character for the
  xdotool, ydotool and wtype backends. Some apps drop keys that arrive too fast; try 4–6.
- **LLM cleanup with your own server.** `[filters.disfluency] llm_api = "openai"` works with a server that serves
  the OpenAI chat route on this machine, and `llm_endpoint_model` names the model.
- **Git names as recognition hints.** With `[context] enabled = true` and `use_git = true`, the focused
  repository's name and branch help recognition. This works on Linux with an X11 session only.
- **Quicker on Wayland.** With ydotool, each dictation finishes about 0.3 s sooner (measured with a stand-in
  ydotool). Nothing typed changes.

## Behaviour changes

- **X11 key-grab (snap, BSD) and macOS: modifier hotkeys start at once.** A hold on Right Ctrl, Right Alt /
  Option or another modifier now starts recording on key-down, not after `hold_threshold_ms`. `space` still waits.
- **ThinkGear headsets (experimental, off by default): fewer events.** An event is now admitted only when the
  headset's own health, the stream check and the signal check all allow it. Expect a short pause after a
  reconnect.
- **Large spoken repeat counts are refused.** "Delete words", "delete lines", "undo" and "select lines" accept
  at most 99.
- **Windows Store build:** the update check makes no network call and says the Store manages updates.
- **The speech detector loads at start-up**, so the first dictation no longer pays for it.

## Fixes

- **Audio decoding library.** PyAV 18.1.0, which reads the files you transcribe, was withdrawn upstream for
  memory corruption with some custom channel layouts. YazSes now requires 18.1.1.
- **Claude Code.** `yazses mcp-server` failed to connect because `serverInfo.version` was missing. It connects
  now.
- **Meeting Mode.** `[meeting] vad_backend = "silero"` crashed on its first chunk.
- **LLM cleanup with Ollama** always asked for one hardcoded model, so other installs silently got raw text back.
- **Phantom text.** A silent press that the speech check could not judge could type a sentence from the built-in
  prompt. Such a transcript is now dropped.
- **Voice commands.** The optional model-based router can no longer pass on an unknown command, or a name or
  shell command that was not spoken.
- **Quit and reopen.** Quit now stops a daemon that does not answer, and reopening the app replaces an idle one
  that started before a permission was granted.
- **Windows Store build.** The microphone and camera checks read the app's own consent entry.
- **Camera features** reopen correctly after being switched off, and the log says when YazSes holds the webcam.
- **Biosignal tools (experimental).** `calibrate`, `field-test` and `monitor` now refuse the signal the daemon
  refuses, a double blink that starts in a refused stretch is rejected, and a too-short `field-test --minutes`
  is refused.

## Not yet verified

- **Toggle dictation and the earlier modifier start on macOS** were checked by reading the code, not on a Mac.
- **The camera switch, tray entry and camera selection** were tested with simulated cameras, not a real webcam or
  video-call app.
- **Local-server LLM cleanup** was tested against a fake server only. No real llama-server, LM Studio or vLLM
  has been tried.
- **The model-based command router** has not been run against a real model since this change.
- **The Windows Store changes** have not run on a real Store install.
- **ThinkGear** changes were checked with simulated serial data only. No headset was used.
- **The phantom-text fix** was tested with a stub decoder, not the real model.
- **The Claude Code fix** was checked for the connection only, not for calling the tools in a session.

What was checked: the full test suite, ruff, mypy and the strict documentation build on the release changes.

The complete list is in the [changelog](https://github.com/MSKazemi/yazses/blob/main/CHANGELOG.md).
