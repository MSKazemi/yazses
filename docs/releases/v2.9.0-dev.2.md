## New since dev.1 (all off by default)

- **Semantic Line Breaks** (ADR-v2-111, `[sembr]`) — breaks dictated prose *one clause per source
  line* (after sentence terminators, `;`/`:`, and comma-led clause words) so git diffs and merges
  stay clean — the rendered output is unchanged. `semantic_breaks(text, max_len)` with optional
  soft-wrap. For anyone versioning prose in git. Anchor: Semantic Line Breaks Spec; ventilated prose.
- **Acronym & Glossary Manager** (ADR-v2-114, `[acronyms]`) — expands an acronym on first mention
  ("World Health Organization (WHO)"), contracts it after, and warns about acronyms you never
  defined. `AcronymState` (observe/define/resolve/audit) using a simplified Schwartz-Hearst matcher
  that handles skip-words (FBI ← "Federal Bureau **of** Investigation") and strips a leading "The".
  Anchor: technical-style first-use convention; LaTeX glossaries/acro.
