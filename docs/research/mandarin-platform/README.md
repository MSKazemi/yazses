# Mandarin platform compatibility reports

Real hardware evidence for Simplified and Traditional Han text injection, collected per
platform/session via the `CHN-COMPAT-*` campaign tasks:

- `linux-x11.md` — Linux, X11 session
- `linux-wayland.md` — Linux, Wayland session
- `macos.md` — macOS
- `windows.md` — Windows

Each report records the exact distro/OS version, desktop or session, YazSes version,
injection backend, the two applications tested, and the fixed Simplified/Traditional test
strings the task specifies — no private dictated text or identifying paths.
